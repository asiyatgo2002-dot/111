# ИИ-агент: топ товаров домашнего текстиля на Ozon и Wildberries

Агент исследует выдачу **Ozon** и **Wildberries** по **домашнему текстилю**, собирает цены,
рейтинги, отзывы и продажи, отбирает лучшие предложения по соотношению **цена/качество
с наибольшим количеством продаж** и сохраняет актуальный **топ-15 в Excel**.

```bash
python -m marketplace_agent          # домашний текстиль — режим по умолчанию
```

Подкатегории домашнего текстиля (`marketplace_agent/categories.py`):

| Подкатегория | Поисковые запросы |
|---|---|
| Постельное бельё | постельное белье |
| Полотенца | полотенца махровые, набор полотенец |
| Пледы | плед |
| Подушки | подушка для сна |
| Одеяла | одеяло |
| Шторы | шторы для комнаты, тюль |
| Покрывала | покрывало на кровать |
| Наматрасники | наматрасник |
| Кухонный текстиль | полотенца кухонные, скатерть |

Особенности категорийного режима:

- **цена/качество считается внутри подкатегории** — полотенце не сравнивается по цене с одеялом,
  а продажи сравниваются по всей категории;
- **в топ-15 попадает не больше 4 товаров одной подкатегории**, чтобы топ не состоял из одного
  постельного белья (`--max-per-subcategory 0` — без ограничения);
- аксессуары (карнизы, крючки, держатели, отдельные наволочки и т. п.) отсекаются по началу названия;
- в Excel добавлены колонка «Категория» и лист **«По категориям»** — топ-5 каждой подкатегории.

Агент работает и с любой другой темой: `python -m marketplace_agent "беспроводные наушники"`.

## Как работает агент

1. **План.** Для домашнего текстиля берутся готовые запросы по подкатегориям; для произвольной
   темы Claude составляет 2–3 запроса так, как их вводят покупатели.
2. **Сбор данных.**
   - *Wildberries*: публичный поисковый API витрины (сортировка «по популярности»)
     и счётчик заказов каждой карточки.
   - *Ozon*: настоящий браузер (Playwright), который проходит антибот-защиту и читает
     JSON выдачи (сортировка «по популярности»), включая бейджи «N купили».
3. **Фильтрация.** Отсекаются товары с рейтингом ниже 4.5, с отзывами меньше 30 и слишком
   дешёвые относительно медианы (обычно аксессуары). Затем Claude убирает нерелевантные
   позиции (чехлы, запчасти, рекламу из другой категории).
4. **Ранжирование** (баллы 0–100):
   - 45% — **продажи** (логарифмическая шкала);
   - 35% — **цена/качество**: байесовский рейтинг на рубль;
   - 20% — **качество**: байесовский рейтинг (4.9 по 10 отзывам весит меньше, чем 4.8 по 10 000).
5. **Выводы.** Claude пишет общий вывод и комментарий к каждому товару топа.
6. **Excel.** `reports/top15_<тема>_<дата>.xlsx` + всегда актуальная копия `..._latest.xlsx`.

### Листы Excel

| Лист | Содержимое |
|---|---|
| **Топ-15** | итоговый рейтинг: маркетплейс, категория, товар, бренд, цена, цена до скидки, скидка, рейтинг, отзывы, продажи, источник продаж, баллы, ссылка, комментарий ИИ |
| **По категориям** | лучшие 5 товаров каждой подкатегории |
| **Wildberries** / **Ozon** | все отобранные кандидаты отдельно по каждой площадке |
| **Все кандидаты** | общая отсортированная таблица |
| **Методика** | дата, запросы, фильтры, формулы, вывод ИИ и ошибки сбора, если были |

## Установка

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium                          # браузер для Ozon
export ANTHROPIC_API_KEY=sk-ant-...                  # Windows: set ANTHROPIC_API_KEY=...
```

Без `ANTHROPIC_API_KEY` агент тоже работает, но без ИИ-шагов (поиск идёт по теме как есть,
без ИИ-фильтра и выводов).

## Запуск

```bash
python -m marketplace_agent                                   # домашний текстиль, топ-15
python -m marketplace_agent "домашний текстиль" --pages 2     # глубже: 2 страницы выдачи на запрос
python -m marketplace_agent --max-per-subcategory 0           # топ без ограничения по подкатегориям
python -m marketplace_agent --marketplaces wb --min-rating 4.7
python -m marketplace_agent --ozon-visible                    # если Ozon блокирует headless-браузер
python -m marketplace_agent "беспроводные наушники"           # любая другая тема
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--top` | 15 | размер топа |
| `--marketplaces` | `wb,ozon` | площадки |
| `--pages` | 1 (категория) / 2 (тема) | страниц выдачи на запрос |
| `--max-per-subcategory` | 4 | максимум товаров одной подкатегории в топе (0 — без ограничения) |
| `--min-rating` / `--min-reviews` | 4.5 / 30 | фильтры качества |
| `--no-ai` | — | не использовать Claude |
| `--output` | `reports/...` | путь к файлу |

Модель задаётся переменной `MARKETPLACE_AGENT_MODEL` (по умолчанию `claude-opus-5-5`).

### Автообновление топа

Чтобы файл `*_latest.xlsx` всегда был актуальным, запускайте агента по расписанию,
например каждый день в 9:00 через cron:

```
0 9 * * * cd /path/to/111 && .venv/bin/python -m marketplace_agent
```

## Важно про данные о продажах

Маркетплейсы не публикуют точные продажи конкурентов, поэтому в колонке «Источник продаж» указано,
откуда взята цифра:

- **WB: заказы (счётчик карточки)** — число заказов, которое Wildberries показывает на карточке;
- **Ozon: бейдж «купили» в выдаче** — округлённое значение («2 тыс. купили»);
- **оценка: отзывы ÷ 5%** — когда площадка число не показывает (на Ozon это частый случай).
  Это приблизительная оценка: обычно отзыв оставляют 3–7% покупателей.

Публичные API и вёрстка маркетплейсов периодически меняются. Если площадка поменяет формат,
агент не упадёт: в листе «Методика» появится примечание о том, какой источник не ответил.
Парсеры собраны в `marketplace_agent/wildberries.py` и `marketplace_agent/ozon.py`.
